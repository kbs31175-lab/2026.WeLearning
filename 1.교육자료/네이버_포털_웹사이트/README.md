# 네이버(NAVER) 메인 포털 클론 프로젝트

네이버 메인 화면의 레이아웃, 시각적 디자인 요소, 반응형 인터페이스 및 동적 기능들을 충실하게 구현한 웹 애플리케이션입니다.

## 📁 파일 구성
- `index.html`: 네이버 메인 포털 마크업 (헤더, 검색창, 서비스 바로가기, EMS 배너, 뉴스스탠드, 프로필 카드, 날씨/광고 위젯, AI 모달 등)
- `style.css`: 네이버 브랜드 컬러(#03c75a), 다크 모드/라이트 모드 테마, 레이아웃 및 애니메이션 스타일시트
- `app.js`: 실시간 급상승 검색어 드롭다운, AI 스마트 검색 도우미 모달, 뉴스스탠드 카테고리 탭 전환, 속보 롤링 티커, 다크모드 토글 등 동적 기능 스크립트
- `server.ps1`: 윈도우 환경에서 즉시 실행 가능한 초경량 로컬 웹 서버 스크립트

## 🚀 실행 방법
1. **단독 브라우저 실행**: `index.html` 파일을 크롬, 엣지 등 웹 브라우저로 더블 클릭하여 바로 엽니다.
2. **로컬 서버로 실행**: PowerShell에서 `powershell -ExecutionPolicy Bypass -File .\server.ps1` 실행 후 `http://localhost:8080` 접속
